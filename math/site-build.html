Axiom

Proposition

math-coding ships a static documentation site built by a POSIX shell script (meta/site-build.sh) that compiles plain HTML, CSS, JS, self-hosted woff2, and SVG into dist/, with no JS framework and no external CDN, deployable to GitHub Pages.

Antithesis

A framework like Astro + Tailwind would be faster to develop, provides hot-reload during development, and offers easier MDX components. Build complexity is invisible to end-users.

Synthesis

Use pandoc --mathml + yq + POSIX shell for the entire pipeline. Pure FP JavaScript for the 2 places where client-side interactivity adds value (live-filter at /packets.html, manual theme override). Self-hosted Source Serif 4 + JetBrains Mono
