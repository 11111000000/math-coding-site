Install

nix develop
sh scripts/install.sh

Builds the OCaml binary, installs to $XDG_DATA_HOME/math-coding/current/math-coding, drops a wrapper at the project root.

Create your first packet

./math-coding packet create cache-ttl \
  --proposition="Cache entries expire after 60 seconds" \
  --antithesis="Manual invalidation forces users to wait" \
  --synthesis="TTL is fixed; manual invalidate is /admin/cache"

Daily workflow

  1. Make code change. git commit -m "..."
  2. ./math-coding check verifies structure.
  3. ./math-coding probe proves the convention applies to itself.

Five commands you need

./math-coding check      # structure + lifecycle of every packet
./math-coding probe      # every axiom packet is sound
./math-coding site       # render dist/ from math/
./math-coding packet show NAME
./math-coding packet edit NAME --antithesis="..."
